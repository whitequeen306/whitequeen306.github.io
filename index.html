About · Agent 工程

我专注做 Agent 自动化系统的工程落地：用 Playwright 驱动真实浏览器环境，把「感知 → 决策 → 执行 → 校验」做成可长期无人值守运行的流水线，而不是一个个孤立脚本。

工程上我更关心那些 demo 里看不见的部分：任务调度与并发编排（流水线分组、失败重试、优雅降级）、对抗性环境下的稳定性（限流熔断、会话保活、页面坏死自愈）、LLM 的可控接入（多模态答题、配额与降级链路、输出解析兜底），以及缓存一致性与幂等终态这类数据正确性问题。

一句话：让 Agent 从「能跑一次」到「跑得久、跑得稳」。
